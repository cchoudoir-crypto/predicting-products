                  Diatomic elements

                  H₂ N₂ O₂ F₂ Cl₂ Br₂ I₂ (HOFBrINCl). Write them this way whenever they appear alone. In a compound, use the ion: NaCl, not NaCl₂.

                  Common ion charges

                  Cross the charge numbers to get subscripts, then reduce: Al³⁺ + O²⁻ → Al₂O₃. Put a polyatomic ion in parentheses if you need more than one: Ca₃(PO₄)₂.
